# المهمة الثانية — بناء تطبيق

[English](README.en.md)

اختر **مسارًا واحدًا**. أي لغة أو إطار عمل أو قاعدة بيانات. المدة المقترحة نحو ست ساعات.

### [المسار (أ) — بناء الواجهة الخلفية للمتجر](track-a-build-the-api/README.md)

نمنحك متجرًا إلكترونيًا جاهزًا بلا واجهة خلفية، وعليك بناء الواجهة الخلفية التي تُشغّله:
المستخدمون، والمنتجات، وسلة المشتريات، وأكواد الخصم، وإتمام الشراء عبر بوابة دفع، وسجل الطلبات.

### [المسار (ب) — بناء واجهة لـ Helm Desk API](track-b-build-the-client/README.md)

نمنحك واجهة برمجية عاملة لنظام دعم فني بلا أي واجهة استخدام، وعليك بناء واحدة — ويب أو جوال:
صندوق وارد للبلاغات، وبحث وتصفية، ومحادثة يمكن الرد عليها، واستلام البلاغات وتصنيفها،
ولوحة تواكب عمل بقية الموظفين لحظةً بلحظة.

كلا المسارين يعمل بأمر `docker compose up`. ولكل مجلّد ملف README خاص به.
