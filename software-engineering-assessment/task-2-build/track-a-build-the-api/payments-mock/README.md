# payments-mock — بوابة دفع تجريبية

[English](README.en.md)

بديل عن معالج البطاقات. يتصرّف كبيئة الاختبار لدى أي مزوّد حقيقي: بطاقات اختبار محدّدة النتائج،
وزمن استجابة واقعي، وقائمة جارية بكل ما تمّ خصمه.

    POST /charge
    { "amount": "42.00", "card": { "number": "4242424242424242", "expiry": "12/29", "cvc": "123", "name": "سلمى الحسيني" }, "reference": "مرجعك لأغراض التسوية" }

    200 { "status": "approved", "chargeId": "ch_...", "amount": "42.00", "reference": "..." }
    402 { "status": "declined", "reason": "card_declined", "chargeId": "ch_..." }

الحقل `reference` اختياري، ويُعاد في الاستجابة ويُحفظ مع عملية الخصم.
استخدمه لربط عملية الخصم بسجلّ لديك عند إجراء التسوية.

    GET /charges    كل ما خصمته هذه النسخة، الأحدث أخيرًا
    GET /health

## بطاقات الاختبار

| الرقم | السلوك |
|---|---|
| `4242 4242 4242 4242` | مقبولة |
| `4000 0000 0000 0002` | مرفوضة |
| `4000 0000 0000 0069` | مقبولة، لكن المعالج يستغرق نحو تسع ثوانٍ للردّ |
| `4000 0000 0000 0119` | المعالج يُرجع خطأ 500 |

أي رقم آخر يُقبل. وكل استدعاء يستغرق 200 إلى 600 مللي ثانية قبل أن ينطبق أيٌّ مما سبق.
الحالة محفوظة في الذاكرة وتُفقد عند إعادة تشغيل الحاوية.
