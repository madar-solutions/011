# Task 2 - build an application

[بالعربية](README.en.md)

Pick **one** track. Any language, framework and database. Budget about six hours.

### [Track A - build the storefront's backend](track-a-build-the-api/)

We give you a finished shop with no backend. You build the backend that makes it work:
customers, catalogue, cart, coupons, checkout against a card processor, order history.

### [Track B - build a client for the Helm Desk API](track-b-build-the-client/)

We give you a working support-desk API with no interface. You build one - web or mobile:
an inbox of tickets, search and filters, a thread you can reply to, claiming and triage,
and a board that keeps up while other agents work.

Both tracks come up with `docker compose up`. Each folder has its own README.
